# 진단 실험 (c): 오답 원인 분류 ("눈" vs "뇌")

수학·화학·물리 오답을 직접 열어 보고, 모델이 **이미지를 잘못 읽어서** 틀렸는지(눈),
**이미지는 맞게 읽었는데 지식·공식·계산·추론에서** 틀렸는지(뇌)를 분류한 자료입니다.
Claude의 판정이 들어 있으므로, **같은 자료로 직접 검증**할 수 있게 구성했습니다.

## 1. 표본 선정 규칙 (고정, 임의 선택 없음)

- 대상 run: `results/runs/M4_final` (본 평가, seed 3407·1·2)
- 과목: Math, Chemistry, Physics
- 조건
  - 3 seed 중 **2개 이상에서 오답**인 문항 (우연한 오답 제외)
  - 그중 seed 3407에서 **`Answer:`로 답을 냈지만 틀린** 문항 (무응답은 제외. 무응답은 별도 분석 대상)
- 조건을 만족한 문항: Math 7, Chemistry 12, Physics 6
  - 문항 번호순으로 과목당 최대 8개를 뽑아 **21문항**
- 재생성: `python scripts/diagnosis/build_review.py results/runs/M4_final <MMMU data_root> results/diagnosis_eye_brain`
  - 이 스크립트는 `labels.csv`를 빈 판정으로 덮어씁니다. 판정을 채운 뒤에는 다시 실행하지 마세요.

## 2. 분류 기준

| 라벨 | 기준 |
|---|---|
| **눈** | 모델이 응답에 적은 **이미지 내용**(수치, 구조, 연결 관계, 위치, 도형 모양)이 실제 이미지와 다르고, 그 차이가 오답으로 이어짐 |
| **뇌** | 응답에 적은 이미지 내용은 맞음. **지식**(사실), **공식·규칙 적용**, **계산**, **추론**에서 틀림 |
| **채점** | 모델의 최종 답이 실제로는 정답인데 채점이 오답 처리함 |
| 혼합 | 눈과 뇌 오류가 모두 있고 어느 쪽이 결정적인지 가리기 어려움 (근거에 적고, 라벨은 결정적인 쪽) |

## 3. 직접 확인하는 방법

1. VS Code에서 `index.md`를 열고 **Markdown 미리보기(Ctrl+Shift+V)**를 켭니다. 각 문항의 "열기" 링크를 누릅니다.
2. 문항 페이지에서 다음 순서로 봅니다.
   - 위쪽의 **정답**과 **모델 최종 답**(3 seed)
   - **이미지**를 보고 직접 핵심 정보를 읽습니다 (예: 그래프의 절편, 간선 목록, 고리 크기, 굴절률).
   - **모델 응답**에서 모델이 이미지를 설명한 부분을 찾습니다. 보통 앞부분의 "Looking at the diagram…", "Let's list the edges…", "We are given…"입니다.
   - 둘을 비교합니다.
     - 다르고, 그 차이 때문에 답이 달라졌으면 **눈**
     - 같은데 뒤의 풀이가 틀렸으면 **뇌**
3. `labels.csv`의 `user_label`에 `눈 / 뇌 / 채점 / 혼합` 중 하나를 적고, `user_note`에 근거를 적습니다.
   - `claude_label`과 `claude_evidence`는 **먼저 보지 않고** 판정한 뒤 비교하는 것을 권장합니다 (선입견 방지).
   - 스프레드시트 앱으로 열어도 됩니다. UTF-8로 저장하세요.
4. 일치도를 계산합니다.
   ```bash
   python scripts/diagnosis/agreement.py results/diagnosis_eye_brain/labels.csv
   ```
   - 일치율, Cohen's kappa, 불일치 문항 목록이 출력됩니다.
   - 불일치 문항은 함께 다시 보고, 합의한 라벨을 최종으로 씁니다.

## 4. Claude 판정 결과 (21문항)

|---|---|---|---|
| Math (7) | 6 | 0 | 1 |
| Chemistry (8) | 4 | 4 | 0 |

| **합계** | **12** | **8** | **1** |

**관찰**
- **Math의 "눈" 오류는 해상도 문제가 아닙니다.** 이미지가 약 400px로 선명한데도 **그래프·도형 구조를 잘못 파악**했습니다 (교차점을 정점으로 봄, 정점 수를 틀림, 영역 경계를 틀림, 타원 장축 방향을 틀림).
- **Chemistry의 "눈" 오류는 작은 이미지에 몰려 있습니다:** 178×85, 약 150px, 256×160. 해상도 확대 실험 (a)로 확인할 대상입니다.
- **"뇌" 오류:** 입체화학 규칙(R/S), 물리 규칙(렌츠 법칙, 박막 위상 반전, 막 속 파장), 사실 지식(모르핀 키랄 중심 수), 산술 실수, 올바른 판독을 스스로 뒤집는 추론 흔들림
- **"채점" 1건 (Math_15):**
  - 정답이 여러 개인 open 문항은 데이터셋에 `"['24/7', '3.429']"` **문자열**로 저장되어 있습니다.
  - lmms-eval 포트의 `eval_open`은 이를 목록으로 풀지 않아서, 맞는 답(`24/7`)도 오답 처리합니다.
  - 해당 문항은 900문항 중 3개(Math_15, Geography_4, Chemistry_30)입니다. 고치면 M4는 seed당 +2문항(+0.22pt)입니다.
