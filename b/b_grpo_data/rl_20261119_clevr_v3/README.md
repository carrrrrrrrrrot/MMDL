# MAmmoTH CLEVR 전용 GRPO 후보 v3 (B 임시 선별)

2026-11-19. 이전 `rl_20261119/mammoth_manifest.jsonl`을 덮어쓰지 않고 별도 버전으로 만들었다. Geo170K 이미지·질문·보기 불일치가 표본에서 반복되어 6000의 해당 학습을 시작하지 않았다. 이 버전은 CLEVR만 사용하며, **C의 누수 검사와 B의 구조·이미지 검사를 통과했으나 C의 문항 품질 승인이나 600건 전수 정답 검수는 받지 않았다.** 실험 결과에는 그 한계를 표시한다.

## 입력과 분할

- A의 3,000건 handoff SHA256: `686114a5a0df098c624e65ef56218ef7916aa7ab1d79bd5308cf2d722ce64e55`, A commit `a61adb899d3c2274ba98cba7a360c5b4f333979f`.
- CLEVR 664건 중 아래 시각 검토에서 의심된 4건을 제외한 660건이 형식 검사에 적합했다. 이미지 SHA256·질문·ID 중복은 없었다.
- 500건 학습 + 100건 내부 보류. 학습에는 A SFT1 사용 121건, A DPO pool 340건 중 240건, DPO pair 106건, A 미사용 33건이 포함된다. DPO pool/pair를 합치면 **A DPO 데이터와 346건이 겹친다**. 보류 100건도 DPO pool과 겹친다. 전체 선별 600건의 A DPO pool/pair 중복은 **446건**이다.
- 학습 500건의 정답 `0`은 128건, A의 원본 기준 `base_k_correct=4`는 192건, `1~3`은 106건(사용 가능한 106건 전부)이다. 부모 SFT1 사용 121건과 A 미사용 33건은 해당 k 값이 없다.
- 보류 100건은 `base_k_correct=4`만 고르고 정답 `0` 50건·그 외 50건으로 맞췄다. 학습 신호가 있는 1~3건을 학습에 남기는 선택이다. **보류 점수는 모델 순위 결정에 쓰지 않는다.** 쉬운 문항으로 편향된 회귀 감시용이다. 후보 순위는 동일한 MMMU v1.2 선별 평가와 최종 공식 평가에서 판단한다.
- MAmmoTH/CLEVR 한 출처만 쓰므로 다른 데이터 종류로 일반화되는 효과를 이 실험만으로 주장하지 않는다.

- A SFT1 사용 121건은 C의 SFT1 12,278건 최종 검사 범위에 속한다. A `c_list_sft1.jsonl`의 `idx`와 출처 및 `sft1_image_hashes.jsonl`의 SHA256을 121건 모두 대조했다. 해당 최종 보고는 검사 범위에서 MMMU·MMMU-Pro 누수 미탐지다.

## 재생성

`build_clevr_v3.py`가 A handoff와 C 감사 원본 4개 및 SFT1 최종 README의 SHA256을 검사하고 동일한 500/100 목록을 만든다. `--handoff`, `--new-audit`, `--sft1-list`, `--sft1-hashes`, `--sft1-report`, `--output`을 모두 지정한다. `--output`은 기존 파일이 없는 경로여야 한다. 선택 규칙은 (1) 위 4개 의심 ID 제외, (2) 새 CLEVR 중 원본 기준 k4·정답0 50건과 k4·비0 50건을 각각 고정 SHA 순위로 보류, (3) 그 외 새 CLEVR 모두 학습, (4) SFT1 사용 CLEVR에서 비0 답을 우선하고 고정 SHA 순위로 121건을 학습에 추가, (5) 학습 순서를 고정 SHA 순위로 정렬이다. 선택 편향은 위에서 설명했다.
