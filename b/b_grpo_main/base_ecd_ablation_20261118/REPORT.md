2026-11-18 KST. C가 승인한 ECD 104문항으로 **원본 모델에서 시작한 보험 경로**를 비교했다. A의 공통 SFT 부모나 DPO를 사용하지 않았다. 이번 세 실행은 먼저 학습과 어댑터를 검증했다. 이후 1024토큰 후보만 6000에서 MMMU 900문항·1시드로 선별 평가했고, 학습률 변경 후보 둘은 아직 평가하지 않았다.

## 기존 900문항 선별 결과와 다음 판정

6000에서 검증된 v1.2 seed 3407 결과는 원본 558/900, [512토큰·64스텝·1e-5 후보](../../b_eval_compare/base_ecd_cap512_steps64_001_screen/REPORT.md) 570/900, [1024토큰·64스텝·1e-5 후보](../../b_eval_compare/base_ecd_cap1024_steps64_20261118_screen/REPORT.md) 564/900이다. 1024토큰 후보는 학습 출력의 답 형식 누락을 줄였지만 같은 시드의 900문항 점수는 512토큰 후보보다 6문항 낮았다. 학습률 5e-6·2e-5 후보는 900문항을 아직 평가하지 않았으므로 성능 변화를 주장하지 않는다. 이들은 모두 원본에서 시작한 보험 경로의 6000 단일 시드 선별 결과이며, 최종 공식 비교는 공통 SFT 부모 후보를 4090에서 3시드 평가해 확정해야 한다.
