2026-11-21 KST. RTX PRO 6000에서 시드 **3407** 한 번씩 평가했다. 두 후보 모두 원본 Qwen3-VL-4B-Instruct revision `ebb281ec70b05090aa6165b016eac8ec08e71b17`에서 출발한 B의 ECD500 강화학습 모델이다. 팀의 공통 SFT 부모나 A의 DPO 뒤에서 시작한 모델은 아니다.

두 후보의 900문항 평가 자체는 정상 종료했다. 순차 실행 큐는 17:03:27~18:39:27 KST에 `finished/complete`, 종료 코드 0을 기록했다. 각각 900개 전부를 채점했고, 기준선과 문항 ID·입력·문서 해시가 900개 모두 일치한다. 평가 스크립트 SHA256도 두 후보에서 동일하다. 병합 모델 및 학습 이력 해시는 각 `candidate_manifest.json`에 보관했다.

이전 300문항 단독 실행과 이번 900문항 실행에서 같은 300개 ID의 정오 판정이 GRPO **29개**, DAPO core **40개** 바뀌었다. 기존 195/300·194/300의 상승이 재평가에서 그대로 유지되지 않았다. 두 실행의 요청 묶음이 다르지만 변화 원인은 이 자료만으로 확정할 수 없다. 고정 300의 점수만 보고 전체 900의 성능을 예측하면 안 된다.

원본의 최종 `Answer:` 누락은 103/900, GRPO는 95/900, DAPO core는 97/900이다. 종료 사유 메타데이터가 없어 누락을 토큰 상한에 따른 잘림으로 단정할 수 없다.

## 해석과 다음 결정

이번 6000·1시드 전체 평가에서는 DAPO core가 GRPO보다 높지만, 원본보다 **1문항** 높은 수준이다. 두 모델 중 어느 쪽도 MMMU 성능 향상이 확립됐다고 보고할 근거는 부족하다. DAPO core를 다음 확인 후보로 둘 수는 있으나, 보고서에서는 **탐색 평가 결과**로 표기해야 한다. 팀의 공식 최종 결과는 합의한 4090 v1.2 평가에서 별도로 확인해야 한다.

두 후보는 같은 ECD500 문항을 사용했지만 학습 코드와 설정이 다르다. 이전 GRPO는 TRL의 512토큰·학습률 `1e-5`·질문당 4개 생성·생성 묶음당 2회 갱신이다. 이번 DAPO core는 EasyR1의 1,024토큰·학습률 `1e-6`·질문당 5개 생성·온라인 보상 필터/비대칭 clip/토큰 단위 손실·15회 갱신이며 긴 응답 길이 벌점은 적용하지 않았다. 따라서 **9문항 차이를 DAPO 알고리즘만의 효과로 해석할 수 없다.** 학습 조건은 [고정 300문항 결과 모음](../ALL_B_FIXED300_20261121.md)과 [Stage 2 완료 보고서](../../b_stage2_ecd500/results/STAGE2_COMPLETE.md)에 기록했다.
