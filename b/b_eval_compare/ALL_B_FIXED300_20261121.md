## 설정과 해석

- **11/19~20 TRL 묶음:** TRL 1.14.2의 `loss_type=grpo/dapo/sapo`를 비교했다. 학습률 `1e-5`, 답변 상한 512토큰, 문항당 4회 생성, 생성 묶음당 2회 갱신이다. 500문항은 1,000 optimizer steps, 혼합 1,000문항은 2,000 steps, ECD798은 1,596 steps이며 ECD798은 798개 고유 문항을 한 번 생성 순회했다. 이때 DAPO는 TRL의 토큰 단위 손실 정규화 선택지이고 온라인 필터·비대칭 clip을 포함한 전체 DAPO 구현은 아니다. SAPO도 TRL의 핵심 손실 선택지다.
- **11/21 EasyR1 묶음:** 학습률 `1e-6`, 답변 상한 1,024토큰, 문항당 5회 생성, 질문 100개당 1회 갱신, 총 15회다. GRPO는 500개 전부를 각 3회 사용했다. DAPO core에는 온라인 보상 필터·비대칭 clip·토큰 기준 손실을 적용했지만 soft overlong 벌점은 사용하지 않았다. ECD DAPO는 500개 중 115개, ViRL DAPO는 500개 중 191개 고유 문항만 실제 갱신에 사용했다.
- ECD798은 기존 ECD500에 A의 SFT1 사용 문항 298개를 더했다. 추가 문항의 정답 품질은 전수 수동 검증되지 않았다. ViRL500 역시 C의 최종 OCR·의미·수동 품질 검토 전이다.
- 이전 ECD500과 11/21 ECD500의 학습 문항 ID 500개는 서로 같다. 평가 입력 ID·시드·원본 기준선도 같지만 학습 코드, 학습률, 생성 수, 토큰 상한, 갱신 횟수와 유효 문항 노출이 다르다. 300문항 1시드 차이로 데이터량이나 손실 함수의 인과 효과, 900문항 성능을 확정할 수 없다. 전체 관측 점수 중 최고는 구 TRL 묶음의 ECD500 GRPO **195/300**이며, 이후 묶음의 최고는 ECD500 DAPO core **194/300**이다.
